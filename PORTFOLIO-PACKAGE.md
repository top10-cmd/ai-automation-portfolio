# AI Automation Portfolio — структура публикации

## 1. AI Support Assistant

Рабочее демо: `index.html`. Техническая схема: `n8n-workflow.json`. Показывает multi-language intake, классификацию, human approval и журналирование.

Подробное описание: `CASE-01-SUPPORT.md`.

## 2. AI HR Assistant

Рабочее mock-демо: `hr-assistant.html`. Показывает извлечение полей вакансии, структурированный JSON, оценку соответствия и персональное письмо.

Подробное описание: `CASE-02-HR.md`.

## 3. AI CRM Lead Assistant

Рабочее mock-демо: `crm-lead-assistant.html`. Показывает intent, приоритет, следующий шаг менеджера и черновик ответа.

Подробное описание: `CASE-03-CRM.md`.

## Формат одного кейса

**Проблема бизнеса → автоматизация → workflow → стек → демо → ограничения → бизнес-ценность.**

## Публикация

- GitHub: разместить HTML, README и n8n JSON без секретов.
- Notion: использовать `portfolio.html` как визуальный каталог и скопировать описания кейсов.
- PDF: экспортировать каталог и страницы кейсов в PDF после финальной проверки.

Видео и музыкальные материалы исключены из текущей версии портфолио по решению автора.

## Важное ограничение

Два дополнительных кейса сейчас работают в безопасном mock/demo-режиме. Для production-подключения нужны backend, LLM API, CRM/табличные credentials и согласованные правила доступа. Секреты должны храниться только в переменных окружения или в credential-хранилище n8n.
