# AI Automation Portfolio — структура публикации

## 1. AI Support Assistant

Рабочее демо: `index.html`, локальный backend: `server.mjs`. Техническая схема: `automation-flow.json`, шаблон приёма для n8n: `n8n-workflow.json`. Показывает multi-language intake, классификацию, human approval и журналирование. Live-адаптер и CRM webhook реализованы, но реальные внешние вызовы ещё не проверялись.

Подробное описание: `CASE-01-SUPPORT.md`.

## 2. AI HR Assistant

Рабочее mock-демо: `hr-assistant.html`. Показывает извлечение полей вакансии, структурированный JSON, оценку соответствия и персональное письмо.

Подробное описание: `CASE-02-HR.md`.

## 3. AI CRM Lead Assistant

Рабочее mock-демо: `crm-lead-assistant.html`. Показывает intent, приоритет, следующий шаг менеджера и черновик ответа.

Подробное описание: `CASE-03-CRM.md`.

## Формат одного кейса

**Проблема бизнеса → автоматизация → workflow → стек → демо → ограничения → бизнес-ценность.**

## Публикация

- GitHub: исходники, README и workflow без секретов. Pages показывает автономный mock, а не серверный live-режим.
- Единая страница: `portfolio.html`, ссылки на все три кейса сохранены.
- PDF: возможный дополнительный формат после проверки; новый PDF в этой версии не создавался.
- Google Docs: только внутренние рабочие материалы. Notion для публикации сейчас не нужен.

Видео и музыкальные материалы исключены из текущей версии портфолио по решению автора.

## Важное ограничение

Два дополнительных кейса остаются прежними mock/demo-страницами. Серверные улучшения этой версии относятся к Support Assistant. Для production-подключения нужны отдельное развёртывание, авторизация, LLM API, CRM/табличные интеграции и согласованные правила доступа. Секреты берутся только из серверного окружения; в workflow их значений нет.
