# Отчёт проверки MVP 0.2

Дата: 7 октября 2026. Windows, Node.js 24.19.0. Только синтетические данные.

## Автоматические проверки

Команда: `node --test --test-isolation=none tests/mvp.test.mjs`.

Результат: **24 пройдено, 0 ошибок, 0 пропущено**. Последний запуск: около 0,73 с.

- 11 языковых примеров: определение языка, непустой черновик и категория.
- Независимость срочности и тональности от темы.
- Неизвестный язык, ручное уточнение и запрет пустого подтверждения.
- Анализ → правка → подтверждение, устаревшая версия, повторное подтверждение и недопустимые переходы.
- Отклонение как конечный статус.
- Сохранение только метаданных, восстановление журнала после перезапуска, отсутствие текстов на диске.
- Ошибка CRM, ручной повтор с тем же ключом и неизменным payload.
- Блокировка параллельных подтверждений, отсутствие отправки до human approval.
- Валидация JSON, длины, synthetic-флага и Content-Type; проверка локальной сессии и Origin; запрет выдачи служебных файлов.
- Bearer-доступ для автоматизации и отказ при неверном токене.
- Структура n8n-шаблона: соединения, входная авторизация, выключенное сохранение выполнений, валидация синтетического запроса, отсутствие автоматического подтверждения.
- Контракт OpenAI Responses: строгая схема, чтение вложенного ответа, маскировка, отсутствие инструментов отправки.
- Отказ модели, неполный ответ, неверный JSON, ошибка провайдера и таймаут без незаметного перехода в mock.
- Неудачный live-анализ не создаёт обращение; успешный всегда требует проверки.

В ограниченной среде отдельные тестовые процессы не запускались из-за запрета spawn; использован встроенный режим Node без изоляции процессов. Сами тесты выполнены полностью.

## Ручная проверка через браузер

1. Локальный backend: английский запрос о срочной доставке → правильные поля анализа → редактирование ответа → сохранение → подтверждение demo.
2. Повторное открытие после обновления страницы: статус, отредактированный ответ и три события истории доступны в текущем серверном запуске.
3. Автономный режим без API: французский возврат → французский черновик → подтверждение demo → обновление → статус сохранён, запись стала архивной без текста.
4. Вёрстка: проверены ширины 1280 и 390 пикселей; горизонтального переполнения страницы не обнаружено. На узком экране карточки идут вертикально.
5. Проверены синтаксис изменённого браузерного модуля и отсутствие отвергнутых заголовков в HTML и трёх CASE-файлах.

## Чего эта проверка не доказывает

- LLM API и CRM имитировались в автоматических тестах. Платные внешние запросы не выполнялись.
- Не проверены семантическое качество реальной модели, все возможные языки и произвольные пользовательские фразы.
- n8n JSON проверен программно; импорт и исполнение в настоящем n8n ещё не выполнены.
- Не проводились нагрузочный тест, аудит безопасности production, проверка всех браузеров и полная проверка доступности.
- GitHub Pages не обновлялся. HR и CRM Lead Assistant сохранены как прежние mock-демо и в новом тестовом наборе не покрыты.

Рабочий результат этого этапа — локальный портфолио-MVP с проверенным mock-процессом и подготовленными интеграционными адаптерами, не развёрнутая production-служба поддержки.
