# Case 02 — AI HR Assistant

## Проблема

Рекрутеру приходится вручную читать вакансию и резюме, сопоставлять требования и каждый раз писать письмо с нуля.

## Решение

Демо показывает, как можно структурировать вакансию и резюме по простым признакам, отметить совпадения и подготовить черновик сопроводительного письма для проверки.

## Workflow

`Job text + CV → признаки → сопоставление → ручная проверка → черновик письма`

Нажать одну кнопку и показать структурированный результат. Процент в публичном демо является условным совпадением по ключевым словам, а не оценкой кандидата.

## Стек

HTML/CSS/JavaScript demo, JSON-ready структура и подготовленная архитектура для будущего подключения LLM API и CRM.

## Ценность

Потенциальная польза — единый первичный разбор и более быстрый переход к проверенному отклику. На синтетическом демо бизнес-эффект не измеряется; кадровое решение остаётся за рекрутером.
