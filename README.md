# LinguaDesk — Multilingual AI Support Assistant

## Бизнес-задача

Сократить время первой реакции службы поддержки и убрать рутинную классификацию обращений. Оператор получает готовое русское резюме, видит приоритет и тональность, редактирует черновик и только затем отправляет его клиенту.

## Что реализовано в MVP

- Приём обращений на русском, английском, немецком, французском и других языках через единое поле.
- Автоопределение языка, темы, срочности и тональности.
- Генерация ответа на языке клиента.
- Краткое резюме для оператора на русском.
- Обязательный human-in-the-loop: подтверждение или редактирование до отправки.
- Локальный журнал времени, языка, темы, приоритета и статуса.
- Синтетические примеры; реальные персональные данные не используются.
- Mock/demo-режим полностью работает без API-ключа.

## Архитектура

`Клиентский текст → Language Detection → Intent/Priority/Sentiment → Draft Reply → Russian Operator Summary → Edit/Approve → Outbound Webhook/CRM`

Сейчас весь pipeline находится в автономной демонстрационной странице. В production отдельные функции можно вынести в backend, добавить LLM-провайдер через переменную окружения `LLM_API_KEY`, а отправку подключить к CRM через `CRM_WEBHOOK_URL`. Секреты в код не зашиваются.

## Стек

Vanilla HTML/CSS/JavaScript для демонстрации без сборки и зависимостей. Для следующего этапа: backend (например, Node.js/FastAPI), LLM API, PostgreSQL/аналитика, n8n или встроенная очередь событий.

## Демонстрационный сценарий

1. Откройте `index.html` в браузере.
2. Выберите один из синтетических примеров или вставьте свой текст.
3. Нажмите «Проанализировать обращение».
4. Проверьте поля анализа и русское резюме.
5. Измените черновик или подтвердите его.
6. Убедитесь, что статус попал в журнал.

## Live-режим

Для live LLM понадобятся backend-адаптер, API-ключ выбранного провайдера и серверные переменные окружения. В браузер ключ не помещается. До подключения live API mock-режим служит безопасным стендом для демонстрации UX и процесса оператора.

## Следующий этап после подтверждения

Подключить реальный backend, структурированный JSON-ответ от модели, валидацию схемы, аудит действий оператора и CRM webhook. n8n-эквивалент подготовлен в `n8n-workflow.json`.
