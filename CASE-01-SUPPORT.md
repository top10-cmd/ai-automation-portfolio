# Case 01 — Multilingual AI Support Assistant

## Проблема

Оператор вручную определяет язык обращения, тему, приоритет и формулирует ответ. Это замедляет первую реакцию и создаёт риск неодинакового качества.

## Решение

Ассистент принимает синтетическое обращение на языке клиента, извлекает структуру, готовит ответ на том же языке, а оператор получает краткое резюме на русском и подтверждает отправку.

## Workflow

`Inbound webhook → normalize → language/intent/priority/sentiment → draft reply → Russian summary → operator approval → CRM webhook → audit log`

Французский запрос о невозвращённой оплате, определённый язык, категория «возврат», русское резюме, черновик на французском и статус «Подтверждено · демо» после подтверждения. Внешняя отправка в demo не выполняется.

## Стек

n8n, LLM API adapter, Webhooks, JSON schema, HTML/CSS/JavaScript, CRM-ready outbound webhook.

## Ценность

Меньше ручной классификации, быстрее первая реакция, единый контроль качества и прозрачный аудит действий оператора.
