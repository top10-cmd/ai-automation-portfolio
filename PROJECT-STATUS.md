# Состояние проекта — MVP 0.2

Дата: 7 октября 2026. Эта версия собрана и проверена локально. В GitHub в рамках этого этапа не загружалась.

## Ссылки

- Локальный каталог: http://localhost:3000/portfolio.html

## Сохранённые решения

- В каталоге четыре кейса: Support, HR, CRM Lead Assistant и AI-assisted Copywriting.
- Удалены только ранее отклонённые заголовки «Что показать работодателю» в описаниях кейсов.
- Заголовок главной страницы — «Как работает решение»; карточки процесса сохранены.
- Видео, запись голоса, музыка и лицензии исключены. Новые аккаунты и платные сервисы не подключались.
- Основной внешний формат — GitHub / Pages, PDF возможен дополнительно. Google Docs — для рабочих материалов.

## Что изменилось

Support Assistant получил полноценную локальную цепочку анализа и подтверждения, серверный API, persistent-журнал только метаданных, live-адаптер и CRM-контракт. Автономное демо работает на 11 языках по правилам. HR-демо сопоставляет вакансию и резюме по ключевым признакам, CRM-демо классифицирует введённый текст лида, а copywriting-страница содержит синтетические примеры.

README описывает реальные ограничения. Ключи не добавлялись. Наличие live-адаптера не означает, что реальные LLM, CRM и n8n уже были подключены: для них требуется отдельная проверка настроенной среды.

## Перед следующей публикацией

1. Посмотреть локальный MVP и утвердить его.
2. Сохранить существующие материалы, загрузить полный согласованный набор новой версии без `.env`, `.data`, `.test-data`.
3. Проверить GitHub Pages по прежним адресам: новая версия использует отдельные `app.js`, `styles.css`, `core.js`.
4. Не представлять GitHub Pages как live LLM backend. Для общего доступа к live понадобится отдельное серверное размещение и доработка безопасности.
